## Mobile Responsive Rules

Desain mobile harus compact dan tidak membuat card terlalu panjang ke bawah.

Aturan wajib:

1. Service card di mobile jangan menampilkan semua list panjang sekaligus.
   Tampilkan maksimal 4 item pertama, lalu beri tombol:
   "Lihat selengkapnya"

2. Untuk card layanan, gunakan layout compact:
   - icon kecil
   - judul
   - deskripsi maksimal 2 baris
   - 4 item layanan dalam bentuk chip kecil
   - CTA kecil

3. Jangan membuat card mobile terlalu tinggi.
   Maksimal tinggi card sekitar 360px sampai 430px.

4. Untuk list layanan panjang, gunakan:
   - horizontal chips
   - accordion
   - show more button
   - atau modal detail

5. Portfolio mobile:
   - gunakan 1 kolom
   - card pendek
   - gambar/placeholder jangan terlalu tinggi
   - deskripsi maksimal 2 baris
   - gunakan line clamp

6. FAQ mobile:
   - wajib pakai accordion
   - hanya jawaban aktif yang terbuka
   - jangan tampilkan semua jawaban sekaligus

7. Testimoni mobile:
   - gunakan carousel atau horizontal scroll
   - card tidak boleh terlalu tinggi
   - quote maksimal 3 baris

8. Contact mobile:
   - contact card dibuat compact
   - form dibuat ringkas
   - tombol WhatsApp sticky di bawah boleh ditambahkan

9. Gunakan CSS line clamp untuk teks panjang:

.card-description {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

.service-list-mobile {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.service-chip {
  font-size: 12px;
  padding: 6px 10px;
  border-radius: 999px;
  background: #f6f8fc;
  color: #091344;
}

10. Pada mobile, jangan pakai padding section yang terlalu besar.
Gunakan:
padding: 56px 20px;

11. Pada desktop, card boleh lebih lengkap.
Pada mobile, prioritaskan ringkas, rapi, dan mudah discroll.
